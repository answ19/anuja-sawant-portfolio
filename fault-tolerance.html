Systems reliability · Fault injection

Fault Tolerance in ML Accelerators.

Exploring how GPU-level faults can affect the behavior and reliability of machine learning workloads, with attention to accuracy degradation and execution outcomes.

PythonCUDACNN reliabilityFault injection
01 / Engineering question

How resilient is a neural network to hardware errors?

Machine-learning workloads run on accelerators that may experience transient faults. This project studied how injected errors affect a CNN's execution and outputs, moving beyond baseline test accuracy to consider robustness under faults.

02 / Approach

Compare baseline and fault-injected behavior.

  • Run a CNN workload to establish baseline predictions and accuracy.
  • Introduce simulated GPU-level faults in controlled experiments.
  • Compare post-injection execution outcomes and model accuracy with the baseline.
  • Analyze how hardware errors can be masked or surface as execution failures or incorrect outputs.

The project used a Python/CUDA-oriented experimental workflow. This overview intentionally avoids unverified performance figures or claims of a deployed production detector.

03 / What it taught me

Reliability is part of the system.

The work reinforced the importance of controlled experiments, baseline measurements, and understanding failure modes when evaluating complex software/hardware systems.
