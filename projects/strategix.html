Strategix BankMarketAI.

Turn machine-learning scores into a practical campaign planning workflow—helping bank teams prioritize term-deposit outreach, explore cost and ROI trade-offs, and export a decision-ready call list.

Co-created by Anuja Sawant and Varshith Sai Manchem. Educational / hackathon demonstration project.

01 / Problem

Which customers should a bank call first?

Marketing teams have finite call time and outreach budgets. Strategix explores how a predicted probability of term-deposit subscription can support lead ranking and campaign planning—not merely produce a classification label. The emphasis is on connecting a model prediction with the decisions a campaign manager needs to make.

02 / Application architecture

One interface, API, and scoring pipeline.

  1. Model and data: A Random Forest classifier built with scikit-learn, pandas, and NumPy using the bank marketing dataset.
  2. API: FastAPI/Uvicorn exposes GET /api/health, GET /api/bootstrap, and POST /api/predict for live customer-profile scoring.
  3. Frontend: React and Vite power a responsive dashboard; Vite proxies /api requests to FastAPI in development.
  4. Deployment workflow: After npm run build, FastAPI can serve the compiled React frontend alongside the endpoints.

The README describes training and caching the model at runtime from bank-additional-full.csv; it does not claim a hosted production deployment.

03 / Product features

From scores to decisions.

  • Lead queue: Rank potential customers and refine by score, priority, age, and job; export a call list to CSV.
  • ROI simulator: Explore changes to campaign threshold, call cost, assumed revenue, profit, and calls saved.
  • Explainability: Feature-importance views and score-band validation to help examine the prediction behavior.
  • Manager brief: Editable campaign summary and recommended outreach list for discussion.
Engineering decision: avoid post-call leakage

The duration field is deliberately excluded from pre-call scoring because that information would not be available before a call. That keeps the prediction workflow aligned with the real decision point.

04 / Scope & evidence

A working demonstration, not a bank deployment.

The project README documents implementation features and local run commands. It does not provide audited business ROI, model accuracy / AUC metrics, or evidence of live customer deployment; the ROI values are simulation outputs, not realized financial performance.

This makes Strategix useful to discuss as an end-to-end application: data preparation, modeling choices, API design, React interface, and communicating model outputs to a nontechnical decision-maker.

05 / Try it locally

Explore the workflow.

With the dataset present and Python dependencies installed, build the frontend and start the API:

cd frontend
npm install
npm run build
cd ..
python -m uvicorn app:app --host 127.0.0.1 --port 8000

Then visit http://127.0.0.1:8000. Follow the repository README for full setup prerequisites.
