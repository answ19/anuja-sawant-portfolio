# Anuja Sawant — SWE WE26 Vibrant Portfolio

A responsive, static portfolio for GitHub Pages. No build step or dependencies are required.

## Test locally

Open `index.html` in a browser, or run `python -m http.server 8000` in this directory, then visit `http://localhost:8000`.

## Deploy to GitHub Pages

Upload the **contents** of this folder to the root of your `answ19/anuja-sawant-portfolio` GitHub repository. In Settings → Pages, choose `Deploy from a branch`, branch `main`, folder `/ (root)`.

Expected (not yet confirmed live): https://answ19.github.io/anuja-sawant-portfolio/

## Site contents

- `index.html`: vibrant homepage with one unified projects collection.
- `styles.css`: responsive styles and light/dark color themes.
- `script.js`: theme switcher.
- `projects/strategix.html`: Strategix full-stack ML case study, with coauthor attribution.
- `projects/ai-request-monitor.html`: AI security prototype case study.
- `projects/pynguin-mvp.html`: test generation and IEEE research case study.
- `projects/fault-tolerance.html`: CNN fault-injection project overview.
- `assets/anuja-headshot.webp`: optimized portrait.
- `resume.pdf` and `resume.docx`: downloadable WE26 resume.

## Project presentation policy

All work appears together without separate coursework / independent-project filters. Project descriptions focus on technical relevance, while collaborator attribution remains explicit when applicable. The Search Engine project is included with a short high-level description because a verified README/repository and stack details are not yet provided. Do not add fabricated metrics, links, or implementation claims.
